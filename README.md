## 📌 Visão Geral
Este projeto é uma automação em Python para criação de documentos Word (.docx) utilizando a biblioteca DocX. O sistema coleta informações do usuário, organiza os dados e gera um arquivo estruturado automaticamente.

---

## ⚙️ Funcionalidades
- Coleta de dados via terminal
- Estruturação de informações em tabela
- Geração automática de documento Word (.docx)
- Definição personalizada do nome do arquivo
- Confirmação de criação do documento ao final

---

## 🧠 Conceitos Abordados
- Manipulação de arquivos Word com biblioteca externa (DocX)
- Entrada de dados via terminal (`input`)
- Estruturas de repetição (`for`)
- Manipulação de listas e contagem de elementos
- Organização de dados em tabelas
- Automação de geração de documentos

---

## 📦 Biblioteca Utilizada
- **DocX** → Responsável pela criação e manipulação de documentos Word

---

## 🚀 Como Executar

- Instalar dependência

```bash
pip install python-docx
```

Executar o script:

```bash
python autoword.py
```
